BLC-400R4E + PG42BL4279 (엔코더 1000CPR / 감속비 1-212)
설정 조합별 거동 정리 — 진동 영상 분석용
작성 2026-09-21
========================================================================
구성  PC + USB-RS485 컨버터(LC529), 9600bps 8N1, ID 0x00, 펌웨어 버전 0
전원  DC24V 150W(6.25A)
지령  위치제어 Mode 0x02, CW 90.00deg, 도달 1.0s
        TX: FF FE 00 06 A1 02 01 23 28 0A
계측  0xA2/0xD2 피드백의 위치 필드(0.1deg 단위). 0xD1 은 655.36deg 에서
        카운트를 흘려 사용 불가 — 아래 수치는 전부 0xD2 기준.

  · 순이동 = 시작점 대비 실제로 옮겨간 각도
  · 총경로 = 매 샘플 이동량의 절대값 합 (왕복하면 커진다)
  · 경로/순이동 = 1.0 에 가까울수록 깨끗, 값이 클수록 왕복 진동

[1] 제어방향 CCW — 폭주 (No.1)
------------------------------------------------------------------------
TX: FF FE 00 03 F0 0C 00             제어 On
TX: FF FE 00 06 97 02 01 23 28 14    위치제어 CW 90.00deg / 도달 2.0s

  t=0.0s  위치   54.71deg  속도   0.8RPM
  t=0.2s  위치  154.78deg  속도 108.0RPM
  t=3.9s  위치  612.50deg  속도 108.3RPM   <- 목표 90deg 를 지나 계속 회전

  3초에 2017deg(5.6바퀴), 20초 방치 시 13000deg 이상. 제어 Off 로만 정지.
  감속비를 1.0:1 로 두면 같은 지령에 3,400RPM 까지 상승.

  위치 초기화(0x0F)를 먼저 보내면 반대로 완전 무반응 (No.2):
TX: FF FE 00 02 EE 0F                위치 초기화
TX: FF FE 00 06 97 02 01 23 28 14    위치제어 CW 90.00deg
RX: FF FE 00 08 26 D1 00 00 00 00 00 00   위치 0.00 / 속도 0.0 / 전류 0.0A
    ... 5초간 동일

[2] 제어방향 CW + 정격전류 25.4A — 격한 진동 (No.3)  ★ 영상 구간
------------------------------------------------------------------------
공장 초기화(0x10) 후 판매처 예제가 지시하는 설정만 등록한 상태.
  분해능 250 (c) / 감속비 2120 (d212) / 제어방향 CW
  위치제어기 Kp200 Ki100 Kd100, 정격전류 25.4A (출고값 그대로)

TX: FF FE 00 04 F7 0A 00 FA          분해능 250 등록
TX: FF FE 00 04 A0 0B 08 48          감속비 2120 등록
TX: FF FE 00 03 EC 0E 01             제어방향 CW
TX: FF FE 00 03 F0 0C 00             제어 On
TX: FF FE 00 06 A1 02 01 23 28 0A    위치제어 CW 90.00deg / 도달 1.0s

  t=0.02s  누적  -2.3deg  속도   0.0RPM
  t=0.12s  누적  -6.3deg  속도   4.7RPM
  t=0.21s  누적  -5.5deg  속도   4.3RPM
  (0.21s ~ 1.51s 구간 피드백 응답 없음 — 진동이 가장 심한 구간)
  t=1.51s  누적   0.0deg  속도   0.0RPM
  총 이동 0.0deg  (2회 반복 동일)

  90도로 가지 못하고 ±6도 범위에서 왕복하다 제자리로 돌아옴.
  수 분 만에 모터가 상당히 발열. 이 상태가 사실상 스톨이므로 전류가
  상한(25.4A)까지 치받는 것으로 보임.

  ※ 변경 직후 별도 시험에서는 목표 정지가 관측되기도 했음:
      지령 CW          ->  -89.7 deg
      지령 CCW         -> +179.8 deg  (2배)
      0x0F 후 지령 CW  ->  -90.7 deg
    같은 설정에서 결과가 갈리므로 재현 조건 확인 필요.

[3] 엔코더 A/B 교차 — 폭주 (No.4)  ★ 중요
------------------------------------------------------------------------
J6-1(A) 과 J6-2(B) 를 서로 바꿔 끼운 상태. 제어방향 CW, 나머지 동일.

TX: FF FE 00 06 A1 02 01 23 28 0A    위치제어 CW 90.00deg / 도달 1.0s

  t=0.04s  누적    46.8deg  속도   64.0RPM
  t=0.16s  누적   134.8deg  속도  110.7RPM
  t=0.99s  누적   685.9deg  속도  123.2RPM
  t=2.02s  누적  1366.9deg  속도  123.5RPM
  총 이동 1396.9deg — 목표에서 멈추지 않고 111RPM 연속 회전

  · 진동은 사라지지만 폐루프가 닫히지 않아 폭주한다.
  · 정상 결선으로 되돌리면 다시 목표에서 멈춘다.
  => 부호가 맞는 쪽은 정상 결선(1번 블랙 EA+ -> J6-1,
     11번 옐로우 EB+ -> J6-2)이며, 진동은 부호 문제가 아니다.

  공장 초기화 후 예제 설정만 적용한 상태에서도 A/B 교차면 동일하게 폭주:
    2초에 1361deg, 111RPM 연속 회전.

[4] 제어방향 CW + 정격전류 1.8A — Kp 별 비교 (No.5~9)
------------------------------------------------------------------------
Ki=100, Kd=100 고정. 위치제어 CW 90.00deg / 도달 1.0s, 2.5초 관측.
정격전류만 25.4A -> 1.8A 로 낮춘 상태.

    Kp    순이동      총경로   경로/순이동   최고속도  응답률
   ---  --------  ----------  -----------  --------  ------
   200   -90.3deg   121.3deg      1.3       23.2RPM   100%   <- 깨끗하게 도달
   150     0.5deg   200.3deg      inf       25.5RPM   100%   <- 제자리 왕복
   100     0.1deg   201.9deg      inf       22.9RPM   100%   <- 제자리 왕복
    60     0.9deg   199.3deg      inf       24.0RPM   100%   <- 제자리 왕복
    30    -0.5deg   176.5deg      inf       22.4RPM   100%   <- 제자리 왕복

  · Kp 를 낮추면 오히려 나빠진다. 150 이하에서는 약 100deg 씩 갔다가
    그대로 되돌아와 순이동이 0 이 된다.
  · 응답률이 전 구간 100% 이므로 계측 누락으로 인한 착시가 아니다.
  · 즉 진동은 게인이 높아서가 아니라 낮아서 발생한다.

[6] 남은 의문
------------------------------------------------------------------------
  1. 같은 Kp200 인데 정격전류 25.4A 에서는 진동, 1.8A 에서는 깨끗하게
     도달했다. 전류 상한이 진동에 관여하는가?
  2. 지령 CW 는 -90도, 지령 CCW 는 +180도로 이동량이 2배 차이난다.
     방향에 따라 이동량이 달라지는 이유는?
  3. 제어방향 CW 변경 직후에는 목표 정지가 되었는데, 이후 같은 설정에서
     진동이 발생했다. 재현 조건이 무엇인가?
  4. 기어박스 백래쉬 3deg(무부하)가 위치 유지에 미치는 영향.

------------------------------------------------------------------------
[7] 전류 상한에 대하여
------------------------------------------------------------------------
기어박스 PG42(1/212) 정격 2.45Nm, 순시허용 7.36Nm.
모터 토크상수 0.185Nm / 4.8A = 0.0385Nm/A, 효율 50%.

  1.8A x 0.0385 x 212 x 0.5 = 약 7.3Nm  -> 순시허용에 상당
  0.6A                      = 약 2.4Nm  -> 연속 정격에 상당
  25.4A(출고값)             = 이론상 100Nm 이상 -> 기어박스 파손 위험

진동 상태는 사실상 스톨이라 전류가 상한까지 흐른다. 시험 시 전류 상한을
1.8A 이하로 두는 것이 안전하다.
