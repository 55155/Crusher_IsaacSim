========================================================================
BLC-400R4E + PG42BL4279 (엔코더 1000CPR / 감속비 1-212)
시험 이력 전체 — 설정값과 결과
========================================================================
구성  PC + USB-RS485 컨버터(LC529), 9600bps 8N1, ID 0x00, 펌웨어 버전 0
전원  DC24V 150W(6.25A)   ※ 초기에는 2.5A 를 쓰다가 교체
부하  전 구간 무부하

계측  0xA2/0xD2 피드백의 위치 필드(0.1deg 단위)
      0xD1 의 위치 필드는 655.36deg 에서 카운트를 흘려 사용하지 않음
      순이동 = 시작점 대비 실제 변위, 총경로 = 샘플별 이동량 절대값 합
      경로/순이동 이 1 에 가까우면 깨끗, 크면 왕복 진동

========================================================================
A. 위치제어 — 제어방향 CCW 시기 (판매처 회신 이전)
========================================================================
이 시기에는 위치제어가 단 한 번도 목표에서 멈추지 않았다.

 A-1 각도별          1 / 3 / 5 / 90 / 360 / 655.33 deg   전부 실패
 A-2 모드            0x01(위치·속도제어), 0x02(가감속 위치제어)  둘 다 실패
 A-3 위치제어 모드    절대 / 상대                          둘 다 실패
 A-4 도달시간        0.1s / 2.0s / 25.5s                  전부 실패
 A-5 감속비          212.0:1 / 1.0:1                      둘 다 실패
 A-6 분해능          4 / 250 / 500 / 1000                 전부 실패
 A-7 위치제어 전류    1.5A / 1.8A / 25.4A                  전부 실패
 A-8 게인            50/10/10 ~ 254/254/254               전부 실패
 A-9 모터 정격속도    100 / 500 / 4000 RPM                 전부 실패
 A-10 제어 On 순서   지령 전 / 지령 후                     둘 다 실패
 A-11 0x0F 유무      보냄 -> 완전 무반응
                     안 보냄 -> 목표 무시하고 폭주
 A-12 공장 초기화    직후에도 동일

  폭주 실측 : 감속비 212.0:1 에서 3초에 2017deg(5.6바퀴), 108RPM
              감속비 1.0:1 에서 6초에 3,400RPM 까지 상승
              20초 방치 시 13,000deg 이상. 제어 Off 로만 정지

  같은 시기 속도제어 : 5.0 / 10.0 / 30.0 / 100.0 / 300.0 / 600.0 RPM 지령
                       -> 전부 약 109RPM 으로 동일. 지령값이 무시됨
                       감속 정지(0.1RPM 지령)도 듣지 않고 제어 Off 로만 정지

========================================================================
B. 제어방향 CW 로 변경 후 (판매처 회신 반영)
========================================================================
판매처 : "모터 기본 방향이 CW 일 수 있으니 제어방향을 CCW -> CW 로 변경"

 B-1 변경 직후 — 목표 정지 성공
       지령 CW          ->  -89.7 deg
       지령 CCW         -> +179.8 deg   (2배)
       0x0F 후 지령 CW  ->  -90.7 deg
     속도제어도 지령에 반응 시작 (14~25RPM 범위)

 B-2 그러나 이후 같은 설정에서 격한 진동 재현
     목표로 가지 못하고 제자리에서 왕복. 수 분 만에 모터 발열

========================================================================
D. 정상 동작이 확인된 부분
========================================================================
 D-1 RS-485 통신
       피드백 200회 요청, 체크섬 불일치 0건
       극성 교차 시 에코만 돌아오고 무응답 -> 현재 극성 정상
       Echo / Non-echo 모드 둘 다 100회 오류 0건
       9600bps 및 115200bps 모두 정상 (115200 에서 폴링 32ms -> 15ms)

 D-2 엔코더
       분리하면 위치·속도 피드백이 0, 재연결하면 정상 출력
       회전 중 위치가 선형 증가
       속도 필드와 0xD2 위치 필드가 일치 (109.6 vs 109.3 RPM, 비율 1.00)
       0xD1 위치 필드만 655.36deg 에서 카운트를 흘림 (7.08배 작게 나옴)
       분해능 500 -> 250 변경 시 보고 속도가 정확히 2배 -> 계수 정상

 D-3 모터·결선
       홀 커뮤테이션만으로 회전 (엔코더 분리 상태에서도 회전)
       상선·홀·엔코더 결선 모두 정상

 D-4 설정 읽기/쓰기
       모든 파라미터가 EEPROM 에 기록되고 전원 재투입 후에도 유지

 D-5 전원
       2.5A -> 150W(6.25A) 교체 후 기동 시 드라이버 리셋 현상 소멸
       (2.5A 에서는 기동 순간 통신이 약 4초 끊기고 위치가 0 으로 초기화됨)

========================================================================
E. PC 측에서 위치를 맞춘 시험 (참고)
========================================================================
드라이버 위치제어 대신 속도제어로 돌리면서 엔코더 피드백을 읽어
목표 각도에서 제어 Off 를 보내는 방식. 제어방향 CCW 시기에 시행.

  9600bps  : 폴링 32ms, OFF 후 관성 28~29deg, 선행 OFF 36deg 로 오차 ±6deg
  115200bps: 폴링 15ms, OFF 후 관성 18.0deg(편차 0.7),
             선행 OFF 30deg -> 오차 -1.4 ~ -7.3deg
             선행 OFF 18deg -> 오차 +1.8 ~ +9.6deg

  오차의 주범은 관성이 아니라 샘플링 해상도.
  폴링 15.7ms x 654deg/s = 약 10deg 마다 한 칸씩 건너뛰므로
  임계값을 넘어선 정도가 매번 달라진다.
