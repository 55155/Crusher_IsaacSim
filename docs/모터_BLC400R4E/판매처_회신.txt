BLC-400R4E + PG42BL4279 (엔코더 1000CPR / 감속비 1-212)
소프트웨어 설정 및 진동 재현 조건 회신
========================================================================
제어 장치 : PC + USB-RS485 컨버터(LC529)
            ※ 아두이노가 아니라 PC 에서 같은 MC-RS485 프로토콜로 제어합니다.
              프레임·체크섬은 상세페이지 예제와 바이트 단위로 일치합니다.
통신      : 9600bps / 8 Data / No Parity / 1 Stop, ID 0x00
전원      : DC24V 150W(6.25A)
상태      : 무부하 (모터 단품, 출력축에 아무것도 연결하지 않음)

------------------------------------------------------------------------
[1] 실현하려는 동작조건
------------------------------------------------------------------------
크랭크 슬라이더 구동입니다.

  · 크랭크 전진  : 속도제어 (Mode 0x03)
  · 크랭크 후퇴  : 위치제어 (Mode 0x02)

  동작 알고리즘
    로드셀에서 들어오는 반력이 120N 이상인 패킷이 연속 10회 누적되면
    -> 즉시 위치제어로 전환하여 역방향으로 90도 회전시킵니다.

  즉 "정해진 속도로 밀다가, 반력 임계값에 도달하면 90도만 되돌린다"는
  반복 동작입니다. 위치제어는 90도 단발 이동만 사용합니다.

  요구 사항
    · 90도 이동이 반복적으로 재현될 것 (누적 오차가 쌓이지 않을 것)
    · 이동 중 진동이 없을 것 (크랭크·기어박스에 충격이 가지 않아야 함)
    · 출력축 기준 저속 구간에서 동작 (기어비 1/212)

------------------------------------------------------------------------
[2] 소프트웨어 설정 (현재값 전체)
------------------------------------------------------------------------
  위치제어기 (0x04) : Kp 200 / Ki 100 / Kd 100 / 정격전류 1.8A
  속도제어기 (0x05) : Kp 200 / Ki 100 / Kd 100 / 정격전류 1.8A
  분해능     (0x0A) : 250          (1000CPR / 4, 상세페이지 예제 규칙)
  감속비     (0x0B) : 2120         (212.0 : 1)
  모터 정격속도(0x09): 1300 RPM     (공장 초기화 후 복귀한 값 그대로 사용)
  제어 방향  (0x0E) : CW           (귀사 회신에 따라 CCW -> CW 변경)
  위치제어 모드(0x0D): 절대
  통신 응답시간(0x08): 100 us
  펌웨어 버전       : 0

  ※ 게인은 출고값(Kp200/Ki100/Kd100)이며, 상세페이지 예제가 게인을 다루지
    않으므로 기본적으로 출고값 그대로 사용했습니다.
  ※ 정격전류만 기어박스 보호를 위해 25.4A -> 1.8A 로 낮췄습니다.
    (PG42 1/212 순시허용 7.36Nm 기준. 토크상수 0.0385Nm/A x 212 x 효율 0.5)

  설정은 모두 제어 Off 상태에서 0.3초 이상 간격으로 등록하고
  되읽기로 확인했습니다.

------------------------------------------------------------------------
[3] 진동 재현 조건  ★ 귀사 요청 사항
------------------------------------------------------------------------
아래 설정에서 위치제어 지령을 주면 매번 재현됩니다.

  지령 프레임 : FF FE 00 06 A1 02 01 23 28 0A
                (가감속 위치제어, CW, 90.00deg, 도달시간 1.0s)

  현상 : 목표 90도로 이동하지 못하고 제자리에서 왕복하며 격하게 진동합니다.
         약 100도씩 갔다가 그대로 되돌아와 순이동이 0 이 됩니다.

  (3-1) 정격전류를 바꿔도 동일 — Kp200/Ki100/Kd100 고정, 2.5초 관측

      정격전류     순이동      총 이동경로    최고 보고속도
      --------  ---------  ------------  -------------
       0.6A       0.1deg      195.9deg      22.9 RPM
       0.6A       0.0deg      193.0deg      23.5 RPM
       1.0A       0.2deg      194.2deg      23.3 RPM
       1.0A      -0.2deg      188.6deg      22.2 RPM
       1.8A       0.9deg      204.9deg      23.6 RPM
       1.8A      -0.9deg      199.9deg      25.2 RPM

      6회 모두 순이동 0, 총경로 190~205deg. 전류는 원인이 아닙니다.

  (3-2) Kp 를 낮추면 오히려 악화 — Ki=100/Kd=100/전류 1.8A 고정

        Kp     순이동      총 이동경로    경로/순이동   최고속도
      -----  ---------  ------------  -----------  --------
        200    -90.3deg     121.3deg       1.3       23.2 RPM  <- 정상 도달
        150      0.5deg     200.3deg       무한       25.5 RPM
        100      0.1deg     201.9deg       무한       22.9 RPM
         60      0.9deg     199.3deg       무한       24.0 RPM
         30     -0.5deg     176.5deg       무한       22.4 RPM

      Kp 200 에서 한 번은 -90.3deg 로 깨끗하게 도달했으나(경로/순이동 1.3),
      같은 설정으로 다시 시험하면 진동이 재현됩니다.
      -> 같은 설정에서 결과가 갈리는 점이 저희가 가장 이해되지 않는 부분입니다.

  계측은 0xA2(속도 피드백)의 위치 필드(0.1deg 단위) 기준입니다.
  0xD1(위치 피드백)의 위치 필드는 655.36deg 에서 카운트를 흘려 사용하지
  않았습니다. 폴링 응답률은 전 구간 100% 로 계측 누락은 없습니다.

------------------------------------------------------------------------
[4] 저속 토크 관련 — 귀사 지적에 대한 관측
------------------------------------------------------------------------
"BLDC 는 저속에서 토크가 일정하지 않아 위치제어 시 떨림이 발생할 수 있다"는
말씀과 부합하는 관측이 있습니다.

  · 속도제어로 자유 회전시킬 때 : 보고속도 약 110 RPM
  · 위치제어 90도 이동 구간     : 보고속도 약 23 RPM  (약 1/5)

위치제어 구간이 확실히 저속입니다. 다만 도달시간을 1.0s -> 3.0s -> 5.0s 로
늘려 더 느리게 해도 진동은 그대로였습니다(최고속도 22.9 -> 8.7 -> 5.9 RPM).

------------------------------------------------------------------------
[5] 함께 확인된 사항
------------------------------------------------------------------------
  · 엔코더 A/B(J6-1, J6-2)를 서로 바꿔 끼우면 진동은 사라지지만
    목표를 무시하고 폭주합니다 (2초에 1397deg, 111RPM 연속 회전).
    정상 결선으로 되돌리면 다시 목표에서 멈춥니다.
    -> 결선 부호는 정상 결선이 맞습니다.

  · 엔코더를 분리하면 모터는 그대로 회전하지만 위치·속도 피드백이 0 이 됩니다.
    다시 연결하면 정상 출력됩니다. 엔코더 자체는 정상입니다.

  · RS-485 통신은 피드백 200회 요청에서 체크섬 불일치 0건입니다.

  · 공장 초기화(0x10) 직후 값 :
      분해능 500 / 감속비 1.0:1 / 정격속도 1300RPM /
      제어방향 CCW / 위치제어 절대 / 게인 Kp200 Ki100 Kd100 / 전류 25.4A
