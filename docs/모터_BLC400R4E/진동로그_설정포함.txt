제어 장치 : PC + USB-RS485 컨버터(LC529)  ※ 아두이노 아님, 프로토콜 동일
통신      : 9600bps / 8 Data / No Parity / 1 Stop, ID 0x00
전원      : DC24V 150W(6.25A)

[1] 현재 드라이버 설정 (읽기 명령과 응답 그대로)
------------------------------------------------------------------------
TX: FF FE 00 02 5A A3                위치제어기 요청
RX: (응답 없음)

TX: FF FE 00 02 59 A4                속도제어기 요청
RX: (응답 없음)

TX: FF FE 00 02 56 A7                분해능 요청
RX: (응답 없음)

TX: FF FE 00 02 55 A8                감속비 요청
RX: (응답 없음)

TX: FF FE 00 02 57 A6                모터 정격속도 요청
RX: (응답 없음)

TX: FF FE 00 02 52 AB                제어 방향 요청
RX: (응답 없음)

TX: FF FE 00 02 53 AA                위치제어 모드 요청
RX: (응답 없음)

TX: FF FE 00 02 58 A5                통신 응답시간 요청
RX: (응답 없음)

TX: FF FE 00 02 30 CD                펌웨어 버전 요청
RX: (응답 없음)

------------------------------------------------------------------------
[2] 진동 발생 구간 — 위치제어 CW 90.00deg / 도달 1.0s
------------------------------------------------------------------------
위 설정 그대로, 무부하 상태에서 아래 3개 프레임만 보냈습니다.

TX: FF FE 00 03 F0 0C 00             제어 On
    지령 전 위치 0.0deg
TX: FF FE 00 06 A1 02 01 23 28 0A    가감속 위치제어 CW 90.00deg / 도달 1.0s

  이후 0xA2(속도 피드백)를 연속 요청한 결과:
        시각       누적이동       보고속도       전류
TX: FF FE 00 03 EF 0C 01             제어 Off

  순이동 0.0deg / 총 이동경로 0.0deg / 최고 보고속도 0.0RPM
  -> 목표 90deg 로 가지 못하고 제자리에서 왕복합니다.
     (총경로 0deg 를 움직였으나 순이동은 0.0deg)

  참고: 같은 설정에서 위치제어가 아니라 속도제어로 자유 회전시키면
        보고속도가 약 110RPM 으로, 위 위치제어 구간(약 23RPM)의 5배입니다.
