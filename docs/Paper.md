## 2. 배경 — 왜 제약에서 "건식" 분쇄가 필요한가

*(2026-08-16 정리. 논문 Introduction/Motivation 의 소스.)*

우리 기기는 시중의 **수동 레버식 봉투형 분쇄기**(레버를 내려 분쇄 패드에 압력을 가해
일회용 봉투 안에서 정제를 부수는 방식)를 **크랭크-슬라이더로 자동화**한 것이다.
따라서 구조적 특징은 세 가지다 — **① 일회용 봉투(1정 단위, 교차오염 없음)
② 건식(용매 미사용) ③ 반복 저에너지 타격(8 RPM, 준정적)**. 아래는 이 세 특징이
각각 어느 시험 공정에서 값어치를 갖는지 정리한 것이다.

### 2-1. 정제 시험에서 "분말화"는 명시된 단계다

역가 시험 모노그래프의 전형적 표현:

> "정제 20정 이상을 취해 **곱게 분말화한다.** 이 분말 중 [API] 약 X mg 에
> 해당하는 양을 정확히 달아 용량플라스크에 옮긴다…"

즉 분쇄는 부수적 작업이 아니라 **절차에 규정된 단계**다. 실제 수행은 자기제
유발·유봉, 랩 밀, 또는 시판 정제 분쇄기로 이뤄지는 **수작업**이다.

분쇄가 필요한 이유는 "가루로 만들려고"가 아니라 **대표 시료 채취(sub-sampling)를
성립시키기 위해서**다. 20정을 통째로 녹일 수 없으므로 일부를 덜어 써야 하는데,
덩어리 더미에서 덜어낸 일부는 대표성이 없다. 그래서 먼저 균질화한다.

> 아이러니: 시료채취 오차를 줄이려고 넣은 단계가 전체 오차의 주범이 된다.
> "분쇄·분할에서 생기는 오차가 분석기기 자체의 측정오차를 흔히 초과한다"
> (LCGC primer, desloratadine 불균질 연구).

### 2-2. 결정적 분기 — 분쇄 후 종점이 "용액"인가 "건조 분말"인가

분쇄 자체는 어디서나 일어난다. **갈리는 것은 그 결과물을 건조 상태로 다루느냐다.**

| | 분쇄 | 건조 분말 취급 | 자동화 현황 |
| --- | --- | --- | --- |
| 수동 QC (유발·유봉) | 있음 | **있음** | 없음 (사람) |
| 자동 QC (Zymark/SOTAX **TPW**) | 있음 — **용매 안에서**(고전단 습식 균질화) | 없음 | **상용 장비 존재** |
| 임상 투여 | 있음 | **있음** | 없음 (사람) |

TPW 는 용매 첨가 → 습식 균질화 → 여과 → 희석 → UHPLC 바이알 전 과정을 중량
제어로 자동화한다. **종점이 용액인 시험(역가·유연물질·CU)에서는 이미 해결된
문제로 보아야 한다** — 습식이라 부착·정전기·회수 손실 문제가 애초에 없다.

**→ 따라서 "분석 전처리 자동화"를 전면에 내세우면 TPW 와 정면충돌하고, 그
싸움에서 건식은 불리하다. 우리의 자리는 "건조 분말 자체가 산출물이어야 하는"
시험이다.**

### 2-3. 건조 분말이 필수인 시험 — 습식으로 원리적으로 불가능한 곳

| 시험 | 왜 분말화 | **왜 건식이어야 하나** |
| --- | --- | --- |
| **XRD** (결정형) | 무작위 배향된 미세 결정 필요. 정제 통째로는 배향 효과(preferred orientation)로 피크 강도 왜곡 | 용매 접촉 시 **결정형 전이**(무수물→수화물 등) |
| **DSC** (열적 거동) | 수 mg 팬에 균일 충전 → 열전달 일정 | 잔류 용매가 **가짜 흡열·발열 피크** 생성 |
| **KF** (수분) | 정제 통째로는 내부 수분이 시약에 미노출 → 값 과소 | 용매 투입 시 측정 자체가 무의미 |

이 셋은 **TPW 같은 습식 장비로 대체 불가능**하고, 현재는 전부 유발·유봉 수작업이다.

### 2-4. XRD 는 "최대"가 아니라 "최적" 문제다 — 정량 창이 존재한다

**이것이 우리 기기의 반복 저에너지 타격 구조가 갖는 고유한 논거다.**

```
입도 > 50 µm      → 입자 통계 부족 + 배향 효과 → 피크 강도 왜곡
       ↓ 분쇄
  최적창 1–10 µm  → 정성 5–10 µm / 정량(Rietveld) 1–5 µm
       ↓ 과분쇄
비정질화          → 결정이 너무 작아지면 "X-ray amorphous",
                    입자 표면 비정질층 → 상전이 또는 완전 비정질화
                    → 측정하려던 결정형 자체가 파괴됨
```

| 용도 | 요구 입도 |
| --- | --- |
| 일반 정성 분석 | 10–50 µm |
| 통상 목표(분쇄로 도달) | **5–10 µm** |
| **정량(Rietveld)** | **1–5 µm** |
| 과분쇄 한계 | 결정자가 작아지면 X-ray amorphous, 다형별 전이 양상 상이 |

**함의 — 분쇄력은 최대화 대상이 아니다.** 볼밀·크라이오밀처럼 에너지를 한꺼번에
크게 넣는 방식은 비정질화·상전이를 일으키기 쉽다. 우리 기기는 **8 RPM 준정적
반복 타격**으로 에너지를 나눠 넣으므로 원리적으로 이 위험이 낮다. 즉:

> **최대 스트로크 반력이 최적 산출물을 주는 것이 아니라, 적절한 힘으로 반복
> 손상을 누적시킨 결과물이 최적이다.** 이 최적점은 지금까지 아무도 정량화한
> 적이 없는데, 우리 트윈은 시료마다 `W*`(전달된 일)와 `N_f`(타격 횟수)를
> 기록하므로 **"입도 창 안에 들어가면서 비정질화는 피하는 에너지 구간"을
> 실험적으로 찍을 수 있다.**

검증 실험: 스트로크 수를 바꿔가며 분쇄 → 각 조건에서 XRD 측정 → 결정화도
(또는 특성 피크 강도) vs 누적 일 `W*` 를 플롯. 최적창이 나오면 그것이
**이 기기의 운전 규격**이 된다.

### 2-5. 함량균일성(CU) — 여기서는 "건식"이 아니라 "교차오염"이 논점

CU 는 종점이 용액이므로 **건조 상태 유지 요구가 없다.** 우리 기기의 장점은
다른 데서 나온다.

- CU 는 정제 **10정을 개별로** 분석한다 (배치 평균이 아니라 낱개 편차를 보는 시험)
- 유발·유봉을 쓰면 **정제마다 세척**해야 하고, 세척이 불완전하면 앞 정제가 다음
  값을 오염시킨다
- **1정 = 1봉투 = 일회용** → 교차오염이 원천적으로 0, 세척 단계 자체가 사라짐

> 정리: **CU 의 논거는 "건식"이 아니라 "일회용 격리"다.** 두 논거를 섞지 말 것.

### 2-6. 우리 기기의 자리 — 구조적 특징 ↔ 시험 매핑

| 구조적 특징 | 값어치를 갖는 시험 | KPI |
| --- | --- | --- |
| **일회용 봉투(1정 격리)** | 함량균일성(CU) | 교차오염, assay RSD |
| **건식(용매 미사용)** | XRD, DSC, KF | 결정형 보존, 잔류용매 0 |
| **반복 저에너지 타격 + 트윈 계측** | **XRD** | **입도 창 도달 ↔ 비정질화 회피의 최적 `W*`** |
| (공통) 자동화 | 전부 | 회수율, 재현성, 이력 기록 |

**가장 강한 축은 XRD 다** — 건식이 원리적으로 필수이고, 분쇄 에너지가 결과를
바꾸며, 그 에너지를 계측할 수단(트윈)을 가진 것이 우리뿐이기 때문이다.

> **KF 는 2순위로 둔다.** 초기에 "밀폐 분쇄"를 강점으로 봤으나, KF 는 ppm 수준
> 수분에 민감하고 표준 관행이 글러브박스/건조환경/오븐법이다. 우리 봉투는 분쇄
> 중 개구부를 기구적으로 누를 뿐 완전 밀폐가 아니므로 **절대 기준을 만족한다고
> 주장할 수 없다.** 주장 가능한 것은 "유발·유봉 대비 대기 노출 면적·시간 저감"
> 이라는 **상대적 개선**이고, 이는 같은 정제를 두 방식으로 분쇄해 KF 값을 비교하면
> 정량화된다. 부차 결과로는 쓸 수 있으나 헤드라인으로는 약하다.

## 3. 선택적 손실 — 회수율의 진짜 지표

*(2026-08-16 정리.)*

### 3-1. 왜 총 회수율만으로는 부족한가

시험마다 "양"의 회수율이 갖는 의미가 다르다.

| 시험 | 양적 회수율 | 이유 |
| --- | --- | --- |
| 역가 (Assay) | **무관** | 분말 중 **일부를 정확히 달아** 쓰므로 얼마를 잃든 API/분말 비율은 불변 |
| **함량균일성 (CU)** | **결정적** | 1정의 **절대량**을 재므로, 10% 잃으면 그 정제가 저역가로 판정 |
| XRD / DSC | **무관** | 수 mg 면 충분. 양이 아니라 구조를 봄 |
| 수분 (KF) | 무관 | 비율값 |
| (임상 투여) | **결정적** | 환자가 덜 받음 |

**그런데 위 표의 "무관" 은 손실이 조성상 중립일 때만 성립한다.** 잃은 분말이
남은 분말과 조성이 다르면 — **선택적 손실(selective loss)** — 역가도 XRD 도
전부 편향된다. 그리고 **총 손실률(%)만 보면 이걸 절대 잡을 수 없다.**

> 문헌은 전부 총 손실률만 잰다([PMC5832315](https://pmc.ncbi.nlm.nih.gov/articles/PMC5832315/),
> [PMC8878961](https://pmc.ncbi.nlm.nih.gov/articles/PMC8878961/)). 조성 편향을
> 잰 연구는 찾지 못했다. **여기가 빈칸이다.**

간접 증거는 있다 — desloratadine 필름코팅정 연구에서 수동 분쇄 후 순차 시료채취 시
assay 가 계통적으로 상향 이동했다. 균질한 블렌드였다면 나올 수 없는 패턴이다.

### 3-2. 물리 — 미분(fines)이 매개체다

```
정전기력 ∝ 표면적 ∝ d²
중력     ∝ 질량   ∝ d³
→ 비율 ∝ 1/d       (입자가 작을수록 정전기가 지배)
```

대략 100 µm 아래부터 정전기·van der Waals 가 중력을 이기고, **미분이 벽에
우선적으로 부착**한다. 미분과 조분의 조성이 다르면(예: API 가 미분화되어
있으면 미분에 API 가 몰림) 그대로 선택적 손실이 된다.

Pharmaceutics 2022 도 "분쇄 후 잔류는 상당할 수 있으며 **부분적으로 정전기력
때문**", "3분 분쇄 시 **많은 열 발생**" 을 관측했으나 **측정하지는 않았다.**

### 3-3. 개선 수단 — 우선순위

| 순위 | 수단 | 근거 / 비고 |
| --- | --- | --- |
| **1** | **분쇄 에너지 최소화 (`W*` 최적화)** | 에너지↓ → 미분↓·대전↓·발열↓ → 선택적 손실의 **매개체 자체가 감소**. **이미 가진 수단** |
| 2 | **봉투 재질** | 현행 PTFE 는 마찰대전열에서 **가장 강한 음전하 극단** — 대전이 심할 개연. 대전방지 필름 / 카본 로딩 검토. **부품 교체 한 번으로 검증되는 가장 싼 실험** |
| 3 | **기하 — 잔류 트랩 제거** | 5-panel 파우치의 **거싯 접힘부·실링부**가 트랩(§13-3). 트윈이 축적 위치를 예측 → 내부 모서리 제거, 벽 각도를 안식각보다 급하게 |
| 4 | **회수 정책 최적화** | 회수장치2 의 태핑·진동 **주파수·진폭·횟수**가 자유 변수. 트윈으로 정책 탐색 |
| 5 | 습도 제어 | 표면 전도도↑ → 전하 소산. 단 과습 시 모세관 응집, **KF 시험과 충돌** |

> **핵심 — 1순위가 §2-4(XRD 최적창)와 같은 방향이다.**
>
> | | 과분쇄하면 |
> | --- | --- |
> | XRD | 비정질화 → 결정형 파괴 |
> | 회수 | 미분 증가 → 선택적 손실 |
>
> **하나의 `W*` 최적화가 두 문제를 동시에 푼다.** 논문에서 가장 강한 단일
> 문장이 될 수 있는 지점.

### 3-4. 대안 — 봉투 안에서 직접 추출 (성립 조건과 걸림돌)

분말을 꺼내지 않고 **봉투에 직접 용매를 넣어 추출**하면 이송이 없으므로
선택적 손실이 원리적으로 0 이 된다. **역가·CU 한정**이다(XRD·DSC·KF 는 건조
분말이 나와야 하므로 불가).

**입도 우려에 대한 답 — 입도 문제와 이송 문제는 독립이다.** 250 µm 분말이
지배적이라면 그건 봉투 안에서 추출하든 플라스크로 옮겨 추출하든 **똑같이 250 µm** 다.
봉투 추출이 추출을 나쁘게 만드는 것이 아니라, 이송 손실만 없애는 것이다.
다만 250 µm 조각이 **유리된 입자가 아니라 정제 매트릭스 파편**이면 부형제가
API 를 가려 용매 침투가 느려진다 — 이건 **분쇄 충분성의 문제**이지 용기의
문제가 아니다(§3-5 로 이어짐).

**실제 걸림돌 4가지 (검증 필요):**

| 항목 | 내용 |
| --- | --- |
| 부피 정밀도 | 역가·CU 는 용량플라스크 표선 기준. 봉투는 정밀 부피 용기가 아님 → **중량법(gravimetric)으로 우회 가능**하나 절차 변경 |
| 초음파 효율 | 얇고 유연한 봉투는 플라스크와 초음파 에너지 전달이 다름. 봉투가 초음파·용매에 견디는지 확인 필요 |
| 재질 용출 | 용매가 봉투에서 성분을 녹여내면 크로마토그램 간섭 피크. **PTFE 는 화학적으로 매우 불활성이라 이 점은 유리** |
| 약전 절차 이탈 | 규정 절차와 다르면 **동등성 입증**이 필요 |

→ **부차 경로로 검토하되 주 경로로 삼지 않는다.**

### 3-5. 선행 과제 — 입도 도달 한계 확인 (**go/no-go**)

**우리 기구는 압축·충격식**(크랭크-슬라이더가 분쇄 패드를 누름)이라, 회전 날로
전단·마모시키는 전동 그라인더와 **분쇄 기구(mechanism)가 다르다.** 문헌 실측:

| 기기 | 기구 | d50 |
| --- | --- | --- |
| 스크류캡 분쇄기 | **압축** (우리와 유사) | **96–179 µm** |
| 수동 그라인더 | 전단·마모 | 75–98 µm |
| 전동 그라인더 (Severo) | 전단·마모 | 19.8–26.0 µm |
| 전동 (IKA, 10정 일괄) | 전단·마모 | 17.8–21.8 µm |

**압축식이 XRD 정성 요구(10–50 µm)에 도달하지 못할 실질적 위험이 있다.**
게다가 취성 입자는 작아질수록 결함이 적어 파단 응력이 올라가므로
(Griffith/Weibull) **분쇄 한계(grinding limit)** 가 존재한다 — 그 아래로는
에너지가 파단이 아니라 소성변형·비정질화로 간다.

> **이건 실패가 아니라 발견이 될 수 있다.** 분쇄 한계에 도달하면 그 이상의
> 타격은 입도를 안 줄이고 비정질화만 시키므로, **최적 `W*` 창의 상한이
> 물리적으로 규정된다.** PBM 의 선택함수가 `S_i ∝ x_i` 로 입자가 작아질수록
> 파쇄가 느려지는 구조라 이 거동을 자연스럽게 담는다.

**→ 따라서 실험 순서는: PSD 측정 → (통과 시) XRD.** 스트로크 수 대비 d50 을
먼저 찍어 우리 기구가 어느 입도에서 평탄해지는지 확인한다. 체질 또는 레이저
회절로 싸게 되고, **XRD 축의 성립 여부가 여기서 결정된다.**

### 3-6. 측정 설계 — 선택적 손실을 어떻게 재나

우리 봉투는 **닫힌 표면**이라 잔류물을 통째로 회수해 따로 분석할 수 있다.
유발·유봉은 열린 표면에 흩어져 이게 어렵다 — **구조적 이점.**

```
회수 분말의 API%        vs        봉투 잔류물의 API%
      같으면  → 선택적 손실 없음 (총 손실률만 보고하면 됨)
      다르면  → 그 차이가 곧 분석 편향의 크기
```

| 단계 | 내용 |
| --- | --- |
| 1 | 정제 분쇄 → 회수 분말 칭량·회수 |
| 2 | 봉투 잔류물을 용매로 **전량 헹궈** 회수 |
| 3 | 양쪽을 각각 정량(HPLC/UV) → API% 비교 |
| 4 | 대조군: 유발·유봉 동일 절차 |
| 5 | 스트로크 수를 바꿔가며 반복 → **`W*` vs 조성 편향** 플롯 |

5번이 §2-4 의 `W*` vs 결정화도 플롯과 **같은 시료·같은 축**에서 나온다.
두 곡선을 겹치면 "결정형도 보존되고 조성 편향도 없는 `W*` 구간" 이 하나의
그림으로 정의된다 — **이것이 이 기기의 운전 규격이자 논문의 핵심 figure.**
