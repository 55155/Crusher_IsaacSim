# Data Inventory — Crusher 실험 · 트윈 · 한계 데이터 정리

Crusher 디지털 트윈에서 **무엇을 실험으로 얻고, 무엇을 시뮬(FEM)으로 얻고,
무엇은 못 얻는가**를 한눈에 정리한 인벤토리. 이론·전략 배경은
[`DigitalTwin.md`](DigitalTwin.md) §7, FEM 구현 현황은
[`../../Crusher_Genesis/FEM/FEM.md`](../../Crusher_Genesis/FEM/FEM.md) 참고.

## 0. 세 범주의 정의 (먼저 읽기)

데이터를 "A 실험 / B 트윈 / C 한계"로 나누는 **기준**을 명확히 한다. 특히 B의
정의가 애매하다는 지적이 있었어 — 아래처럼 못 박는다.

| 범주 | 정의 (한 줄 기준) |
|---|---|
| **A. 실험으로 얻는 값** | Crusher·정제에 **센서를 붙이거나 직접 셀 수 있는** 바깥에서 관측 가능한 양 (힘·횟수·시간·일의 *총합*) |
| **B. 트윈으로 얻어야 하는 값** | 아래 **둘 중 하나**에 해당하는 값 |
| **C. 못 얻는 값** | 실험도 시뮬도 (현재 또는 원리적으로) 줄 수 없는 양 |

**B의 정확한 정의 — 둘 중 하나면 "트윈으로 얻어야 하는" 값이다:**

1. **(내부량) 실험이 원리적으로 못 보는 것** — 정제 *내부*의 응력장 `σ_I`,
   내부 변형률, 균열 핵의 위치·시점. 실험은 표면 힘과 최종 결과(깨졌나/언제)만
   보지, "왜·어디서" 깨졌는지는 못 본다.
2. **(예측량) 실험을 돌리지 *않고* 얻고 싶은 것** — **같은 처방**의 새 형상에
   대한 `N_f`·`W*` 예측. 목적은 *실험 횟수 절약*.

> 즉 B = "실험이 **못 보거나(내부)** **보기엔 비싼(예측)** 것"을 시뮬이 채운다.
> 이 두 경우가 아니면 그냥 A(실험)로 얻는 게 맞다.

여기서 **"처방(formulation)"** = 약의 재료 레시피(주성분 + 충전제·결합제·붕해제·
활택제 비율 + 타정압). 정제의 물성(E, ν, σ_t, ρ)은 *처방*이 결정하고 *형상*과는
독립 → 한 처방을 실험 1회로 보정하면, 같은 처방의 다른 형상은 시뮬 예측만으로 커버.

## A. Crusher + 정제로 *직접 측정*하는 데이터 (실측)

| 데이터 | 단위 | 측정 방법 | 용도 |
|---|---|---|---|
| 모터 토크 / 전류 | N·m | 드라이버 전류 → 크랭크 힘 환산 | F_peak·일 계산의 입력 |
| 크랭크 각도·각속도 | rad, rad/s | 엔코더 | 스트로크 속도, 운동학 |
| **타격 힘 F_peak** | N | 토크 × 크랭크암, 또는 로드셀 | regime 판정 (vs F_threshold) |
| **N_f (파쇄까지 스트로크 수)** | 회 | 첫 균열까지 육안/카메라 카운트 | ✅ 가장 직접적인 트윈 검증값 |
| 파쇄까지 시간 | s | 스트로크 수 × 주기 | N_f와 등가 |
| **W_motor (모터가 한 일)** | J | ∫ τ·ω dt 적분 | W* 추정의 상한 (손실 포함) |
| 정제 경도(hardness) | N | 별도 경도시험기 | σ_c ≈ Hardness / 접촉면적 |
| **인장강도 σ_t** | Pa | Brazilian(직경방향 압축) 시험 | 파단 판정의 재료 기준값 |
| 질량 / 형상(3D scan) / 곡률 | kg, m | 저울, 스캐너 | ρ, FEM 메쉬 입력 |
| 파쇄 후 조각 크기분포 | m | 사후 체질/이미지 | 분쇄 품질(2차 지표) |

> 핵심: 실험은 **"바깥에서 보이는 양"**(힘·횟수·시간·일의 *총합*)만 준다.
> **"왜·어디서 깨졌나"** 는 못 본다.

## B. 트윈(FEM)으로 *얻어야* 하는 데이터 — 실험이 못 보는 내부값·예측값

| 데이터 | 단위 | B 정의 | 왜 시뮬인가 | 현재 상태 |
|---|---|---|---|---|
| **σ_I 응력장 (최대 주응력)** | Pa | ①내부 | 균열 *핵 위치·시점*은 내부 응력집중부 | ✅ 탄성 FEM |
| von Mises / 주응력 분포 | Pa | ①내부 | 파단 판정 표준, 내부값 | ✅ 후처리 |
| **F_threshold (단일타격 파쇄력)** | N | ①내부 | σ_I=σ_t 되는 peak force | 후처리 추정 |
| 내부 변형률 ε | — | ①내부 | 부위별 변형 분포 | ✅ |
| **새 형상의 N_f·W\* forward 예측** | 회 / J | ②예측 | **같은 처방** 다른 형상을 실험 없이 | 손상규칙 필요 |
| regime 분류 (I/II/III) | — | ①+② | F_peak vs F_threshold | ✅ |
| material card (E, ν, σ_t) | Pa | ②역추정 | 실험 N_f·W*로 *역보정* | 캘리브레이션 루프 |

> 핵심: 트윈은 **"안에서 일어나는 일"**(응력장·균열 시작점)과 **"실험 안 한 형상의
> 예측"**을 준다.

## C. *얻을 수 없는* / 현재 막힌 데이터 (한계)

| 데이터 | 이유 | 우회책 |
|---|---|---|

| 절대 변형에너지 [J] | `elements_el_energy` 단위 버그 ~10⁹배 (FEM.md §4.5) | node 변위로 ∇u 직접 적분 |
| **파단/손상 누적 모델** | Genesis 기본 FEM에 손상모델 **없음** | 외부 후처리, pre-fracture hack (FEM.md §4.7) |
| 파쇄 *후* 조각 거동 | 표준 FEM은 메쉬 고정 — fracture 한계 | MPM/입자법 영역 (트윈 범위 밖) |

| 미시 균열 경로·화학변화 | 연속체 가정 붕괴, 물리 범위 밖 | data-driven fallback (DigitalTwin.md §9) |

## D. 데이터 흐름 — A로 B를 보정, B로 확장

```
A(실험: N_f, W_motor, F_peak)  ──역보정(calibration)──▶  B: material card (σ_t, E)
                                                              │
                                                        forward FEM
                                                              ▼
                                      B: 같은 처방·새 형상의 N_f·W* 예측
```

A는 **검증·보정의 ground truth**, B는 **내부 가시화 + 미실험 형상 확장**. C는
경계를 알고 우회·근사하는 영역.

## E. "S-N 곡선" 재검토 — 알약에 그대로 쓰면 안 된다

이전 논의에서 반복 타격 파쇄를 **S-N 곡선**으로 묘사하자는 얘기가 나왔는데,
"알약은 알루미늄·철 같은 균질 재료가 아닌데 S-N으로 보는 게 의미 있나"라는
지적이 있었다. **이 지적이 재료적으로 옳다.** 정리한다.

### E-1. 왜 금속식 S-N이 알약엔 부적절한가

| 구분 | 금속 S-N (Wöhler) | 알약(정제) |
|---|---|---|
| 재료 | 균질·연성 금속 | **압축 분말 성형체** (다공성·취성·불균질 granular compact) |
| 손상 기구 | 주기적 **소성** 손상 누적 (전위·미세균열 성장) | 충격당 **취성 미세균열 생성·합체** (소성 거의 없음) |
| cycle 수 | 10³–10⁷ (고주기 피로) | 수~수십 회 (저주기 충격 손상) |
| 곡선 의미 | **재료 상수**에 가까움 | 이 정제(처방+형상) 고유의 **현상론적 곡선** |

→ 알약에서 일어나는 건 금속 *피로*가 아니라 **반복 충격에 의한 손상 누적/분쇄
(comminution)** 다. 광물·콘크리트의 반복충격 파쇄(breakage probability, Bond work
index)에 더 가깝다.

### E-2. 그럼 무엇으로 부르고, 무엇을 측정하나

- "S-N 곡선"이라는 **이름을 버리고**, 실제로 우리가 쓰는 건
  **F_peak ↔ N_f 경험적 파쇄(breakage) 관계** (또는 *충격당 파쇄확률*)다.
  이건 **재료 상수가 아니라** 특정 정제에 대한 fit/lookup 곡선임을 명시한다.
- **진짜 재료 물성**은 따로 있고, 정제에 맞는 표준은:

  | 물성 | 측정/의미 |
  |---|---|
  | **σ_t (인장강도)** | Brazilian(직경압축) 시험 — 정제 강도의 **표준 시험** |
  | **Weibull modulus** | 취성 강도의 *산포* (불균질·결함 분포 반영) |
  | **G_c (파괴에너지)** | 단위 면적당 균열 생성 에너지 |
  | **porosity / ρ** | 타정압의 결과, 강도와 직결 |

### E-3. 트윈에서의 역할 분담 (결론)

- **FEM(B)**: 단일 타격의 `σ_I` 응력장 → `F_threshold`, 그리고 *충격당 응력*을 제공.
- **손상 누적(현상론)**: 그 응력을 입력으로 **damage rule**(예: 누적손상 D += f(σ),
  D≥1이면 파쇄)을 적용 → `N_f`. 금속 S-N이 아니라 **취성 손상누적/Weibull 기반**으로.
- **실험(A)**: `F_peak`–`N_f` 점들을 직접 찍어 위 규칙을 보정. 물리모델이 끝내
  안 닫히면, 이 점들 자체를 **data-driven 매핑**으로 쓰는 것이 한 박사님 피드백
  (DigitalTwin.md §9)의 fallback과 일치.

> 한 줄 결론: **반복 타격 거동은 "S-N 곡선(재료 상수)"이 아니라 "이 정제의
> 경험적 파쇄/손상누적 곡선"으로 봐야 한다.** 재료 고유값은 σ_t·Weibull·G_c로
> 따로 잡고, F–N_f는 그 위에 얹힌 현상론적 fit으로 취급한다.
